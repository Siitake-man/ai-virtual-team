# ガイド：session-start スキルの使い方

**対象プロジェクト**: AI Virtual Team Builder  
**スキルファイル**: `.agents/skills/session-start/SKILL.md`

---

## このスキルは何をするのか？

新しい開発セッションを始めるとき「前回どこまでやったか」「Julesが何かやってくれたか」を**AIが自動でスキャンして整理**し、「今日の最初の5分タスク」を提示するスキルです。

| やること | 自動化の内容 |
|:---|:---|
| ① コンテキスト復元 | `docs/task.md`, `docs/implementation_plan.md`, 最新の学習メモを読み込む |
| ② Jules成果確認 | `docs/handover/jules_handover_*.md` を読み込んで成果を把握する |
| ③ 環境チェック | `.env` の設定状態を確認する |
| ④ 5分タスク特定 | 今すぐ着手できる最小タスクを1つ提示する |
| ⑤ 再開宣言 | 上記すべてをまとめてユーザーに報告する |

---

## 使い方（2ステップ）

### Step 1：セッション開始時にチャットで呼び出す

チャット欄に以下の「魔法のプロンプト」を入力します（前回のsession-wrap-upで生成されたもの）：

```
session-start
```

または、前回のsession-wrap-upが生成した「次回再開時の魔法のプロンプト」をそのままコピペします。

### Step 2：AIの再開宣言を読んで「はい」と答える

AIが以下を報告します：

1. 前回どこまで完了したか
2. Julesが何をやってくれたか（あれば）
3. `.env` のキー設定状態（値は表示しない）
4. 今日最初にやる5分タスク

問題なければ「はい」または「OK」と返答するだけで作業が開始されます。

---

## 前提条件

前回のセッションで `session-wrap-up` を実行し、以下が存在していること：

- `docs/learning-memos/学習メモ_YYYYMMDD.md`（前回の振り返り）
- `docs/task.md`（最新ステータスに更新済み）

---

## Julesの成果を受け取るときの流れ

1. 前日にJulesが作業してPRを作成
2. 翌朝、GitHubのPRを `git pull` してローカルに取り込む（自分で実行）
3. チャットで `session-start` を入力
4. AIがJulesの `jules_handover_*.md` を読んで変更点を説明
5. 確認後、続きの実装に進む

---

## 主要なファイルパス（このプロジェクト固有）

| 用途 | パス |
|:---|:---|
| タスク管理 | `docs/task.md` |
| 実装計画 | `docs/implementation_plan.md` |
| 仕様書 | `SPEC.md`, `GEMINI.md` |
| 学習メモ保存先 | `docs/learning-memos/` |
| Jules引き継ぎ受け取り | `docs/handover/jules_handover_*.md` |
| アプリ起動コマンド | `.\run.ps1`（ターミナルで手動実行） |

---

## 注意事項

- アプリサーバー（`run.ps1`）の自動起動はAIが行いません。自分でターミナルで実行してください
- `git pull` も自動実行しません。Julesの成果を取り込む際は自分で実行してください
- `.env` のAPIキーの値はチャットに表示されません（セキュリティのため）
