## 🏗️ 作ったアーキテクチャ概要

### 二重プロセス構成とは？

今回のアプリは「お店本体（FastAPI）」と「看板・窓口（Streamlit）」が別々のプロセスで動いている。

```
ユーザーのブラウザ
    ↕ HTTP (port 8501)
[Streamlit フロントエンド] ← Python処理 + UIレンダリング
    ↕ HTTP (port 8000)
[FastAPI バックエンド] ← ビジネスロジック + データ管理
    ↕ ファイルI/O
[JSON ファイル (data/projects/)] ← データの永続化
```

**なぜこの構成にするのか？（Why）**

将来Webサービスとして公開するとき、「フロントエンドをNext.jsに差し替え」「データベースをSupabaseに切り替え」が容易になるため。FastAPIとStreamlitを最初から分離しておくことで、将来の移行コストを最小化する（拡張性の原則）。

## 🔑 今日学んだ技術の概念

### 1. Pydantic（データの型定義）

**What**: Pythonのデータクラスをより厳密にしたライブラリ。「どんなデータ構造が正しいか」をコードで宣言する。

**Why**: FastAPIがこれを使うことで、APIへのリクエスト内容が仕様通りでない場合に自動でエラーを返す。入力チェックを手作業で書く必要がなくなる。

**身近な例え**: 会社の「書類提出フォーム」のようなもの。「名前」「日付」「金額」という欄がある書類のテンプレートを定義しておくと、欄外の記入は受け付けてもらえない仕組み。

**今回の実装例**: `Project`, `Employee`, `OwnerContext` などのスキーマ定義（`app/models/schemas.py`）

---

### 2. リポジトリパターン（データアクセスの分離）

**What**: データの読み書き（保存・取得・削除）の処理を、UIやビジネスロジックから「リポジトリ」クラスに切り出す設計パターン。

**Why**: 「今はJSONファイルに保存するけど、将来Supabase（クラウドDB）に移行したい」というとき、リポジトリクラスだけを差し替えれば済む。他のコードは一行も変えなくていい。

**身近な例え**: 会社の「備品管理担当者」。「〇〇を注文したい」と言えば、Amazonで頼もうと楽天で頼もうと、依頼者（ビジネスロジック）は気にしなくていい。調達ルートを変えても、依頼の仕方は変わらない。

**今回の実装例**: `app/repositories/json_repository.py`

---

### 3. FastAPIのルーターとDependency Injection

**What**: FastAPIのルーターはAPIのURLとその処理を束ねるファイル分割の仕組み。Depends（依存性の注入）は、ルーター関数が必要とする依存部品（例: リポジトリ）を自動で渡す仕組み。

**Why**: 機能ごとにファイルを分けると、コードが整理されてメンテナンスしやすくなる。また、テスト時に「本物のリポジトリ」を「モックリポジトリ」にすり替えることも容易になる。

**身近な例え**: 飲食店のホールスタッフとキッチンの分業。「注文を受ける窓口（ルーター）」と「実際に料理を作る（サービス・リポジトリ）」が分かれていて、それぞれが専門に集中している。

**今回の実装例**: `app/api/routers/projects.py`, `employees.py`, `chat.py`

---

### 4. google-genai SDK の使い方（最重要）

**What**: GoogleのGemini APIをPythonから呼び出すための公式ライブラリ（v1.0以降の新SDK）。

**今回覚えた使い方**:
```python
# 1. クライアントの初期化
from google import genai
from google.genai import types
client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

# 2. システムプロンプト + 会話履歴でリクエスト
response = client.models.generate_content(
    model="gemini-2.0-flash",
    contents=contents,  # ← role: "user"/"model" の配列
    config=types.GenerateContentConfig(
        system_instruction="あなたは批判的思考のアドバイザーです...",
        temperature=0.7,
    )
)
print(response.text)  # ← 返答テキスト
```

**なぜtypeを"model"と書くのか**: Google APIの仕様で、AIアシスタント側の役割を`"model"`と定義している（他のAPIの`"assistant"`と意味は同じ）。

---

### 5. Streamlitの「st.chat_message」と「st.chat_input」

**What**: Streamlitにビルトインされているチャット型UIコンポーネント。

**Why**: `st.chat_message("user")` で「吹き出し型」のユーザーメッセージ欄、`st.chat_message("assistant")` でAIの回答吹き出しが即座に作れる。

**身近な例え**: LINE・Slackのような「バブル型」のチャットUIを、数行のコードで出せる。

## 🐞 ハマったトラブルと解決策

| トラブル | 原因 | 解決策 |
|:---|:---|:---|
| `google-genai==0.1.1` がインストールできない | 存在しないバージョンを指定していた | `>=1.0.0` に変更（最新版を自動取得）|
| `numpy` のコンパイルエラー | Python 3.13に対してビルド済みパッケージが古いバージョンに存在しない | ライブラリ指定を `==` から `>=` に変更し、最新のビルド済みホイールを使用 |
| `ModuleNotFoundError: 'app'` | `streamlit run app/main.py` 実行時にPythonのパス探索がプロジェクトルートを含まない | `sys.path.append(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))` をファイル先頭に追記 |
| サイドバーのフォームで文字が被る | `st.form` がサイドバーの幅でEnterキーのヘルパーテキストを折り返し、入力欄と重なる | `st.form` を廃止し、通常の `st.text_input` + `st.button` に変更 |
